1\. **FastAPI** — що це?

FastAPI — це сучасний Python-фреймворк для створення API (інтерфейсів, через які програми спілкуються між собою). Наш сервер буде отримувати запити (наприклад, від браузера чи фронтенду) і повертати відповіді.



2\. **CORS Middleware** — навіщо?

Це захисний механізм браузера. Без нього браузер блокуватиме запити з іншого домену. Ми дозволили "\*" (всі джерела) — це зручно для розробки, але на продакшні треба буде обмежити.



3\. **/health ендпоінт** — навіщо?

Це як "пульс" сервера. Відкриваєш http://localhost:8000/health і бачиш {"status": "ok"} — значить сервер живий і працює. Такі перевірки стандартні у всіх проєктах.



4\. **Uvicorn** — що це?

Це швидкий веб-сервер, який запускає наш FastAPI додаток. reload=True означає — якщо змінюєш код, сервер перезапускається автоматично. Дуже зручно під час розробки.
